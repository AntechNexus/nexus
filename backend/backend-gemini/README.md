# Backend Gemini Service

This is a microservice dedicated to interfacing with the Gemini AI model. It provides endpoints for summarizing documents, transcribing audio/video, and extracting insights.

## Port configuration
- By default, it runs on port `5001`.

## Environment Setup
1. Copy the example env file: `cp .env.example .env`
2. Configure the following key variables:
   - `GEMINI_API_KEY`: Your Google Gemini API key.

*Note: This service does NOT require a `JWT_SECRET`. It is intended to be called internally by `backend-nexus` which handles user authentication.*

## How to Access Endpoints

The `backend-gemini` service primarily acts as an internal AI processing microservice, but it also exposes endpoints that the frontend calls directly (e.g., Ask Nexus). 

For endpoints that require authentication (like Ask Nexus routes), you must provide the JWT token generated by `backend-nexus` in the `Authorization` header:
```
Authorization: Bearer <your_jwt_token>
```

## API Endpoints Reference

### 1. Document & PRD Processing (`/api`)
These endpoints handle file uploads, PRD generation, and transcriptions.
- `POST /api/upload`: Uploads and processes multiple files (`multipart/form-data` with `files` field).
- `POST /api/generate-prd`: Generates a Product Requirement Document based on provided context/files.
- `GET /api/files/:id/transcribe`: Triggers transcription for a specific audio/video file.
- `PUT /api/files/:id/transcribe`: Updates an existing transcription.
- `GET /api/files/:id/summary`: Generates an AI summary for a specific file.

### 2. Ask Nexus (Chat/Copilot) (`/api/ask-nexus`) - *Protected*
These endpoints handle the AI chat copilot features and require a valid Bearer Token.
- `POST /api/ask-nexus/ask`: Ask a new question or continue an existing conversation with the AI.
- `POST /api/ask-nexus/regenerate`: Ask the AI to regenerate its previous response.
- `GET /api/ask-nexus/conversations`: Retrieve a list of all conversations for the authenticated user.
- `GET /api/ask-nexus/conversations/:id`: Retrieve the chat history for a specific conversation.

### 3. Embeddings (`/api/embeddings`)
- `POST /api/embeddings/generate`: Triggers the generation of vector embeddings for documents (used for Retrieval-Augmented Generation).
